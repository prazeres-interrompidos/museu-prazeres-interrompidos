MUSEU VIRTUAL PRAZERES INTERROMPIDOS — ARQUITETURA V3

Substituir no repositório:
    museum_architecture.js

Não é necessário substituir:
    index.html
    room_builder_aux.js

A V3 mantém o motor OpenVGal, a navegação e o sistema de capas das salas.
A sala root passa a ser construída integralmente por código e não usa a arquitetura
visual do template antigo.

Importante:
1. Fazer uma cópia do museum_architecture.js atual antes de substituir.
2. Copiar o novo museum_architecture.js para a raiz do repositório.
3. No GitHub Desktop, fazer Commit e depois Push origin.
4. Aguardar o GitHub Pages publicar.
5. No navegador, usar Ctrl+F5.

A root não inicia o carregamento do template antigo. O carregamento visual da root
é encerrado directamente depois da construção da arquitectura própria.
